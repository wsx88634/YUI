IOGEAR GWU637 操作與設定指南

Ethernet-to-Wi-Fi Universal Wireless Adapter 快速圖解說明書

GWU637 | USER GUIDE
1 產品簡介與硬體連接示意圖

IOGEAR GWU637 能將無無線網路功能的有線設備（如智慧電視、印表機、舊型電腦、IP Camera）轉接連接至無線 Wi-Fi 網路。

圖 1：GWU637 轉接器與設備、路由器連接關係圖
2 設定方案一：WPS 一鍵快速連線（推薦）
圖 2：WPS 按鍵一鍵自動配對流程圖
1
供電與連接

使用 USB 線插入轉接器供電，並將 RJ-45 網路線插入電腦或電視的有線網口。

2
按壓 GWU637 的 WPS 鍵

長按 GWU637 上的 WPS 按鈕約 3～5 秒，觀察面板上的 WPS 指示燈開始閃爍。

3
啟動無線路由器 WPS 鍵

在 2 分鐘內，按下家中無線路由器上的 WPS 按鈕，兩台設備將自動配對並完成連線。

3 設定方案二：網頁介面手動設定（無 WPS 時使用）
圖 3：透過電腦瀏覽器登入 192.168.1.252 設定 Wi-Fi
1
設定電腦靜態 IP (Static IP)

將電腦以網線連接 GWU637 並關閉電腦 Wi-Fi。將電腦以太網 IPv4 設定為：
IP 位址：192.168.1.3 | 子網路遮罩：255.255.255.0

2
開啟瀏覽器並登入管理網頁

開啟 Safari / Edge 瀏覽器，輸入預設 IP 192.168.1.252。
預設帳號：admin | 預設密碼：admin

3
進行無線網路掃描 (Site Survey)

點選「Site Survey」選單，掃描並選取您家中的 Wi-Fi SSID，輸入 Wi-Fi 密碼後點擊 Connect。

4
恢復電腦網路設定為 DHCP

設定完成後，切記將電腦 IP 設定還原為「自動取得 IP 位址 (DHCP)」，即可正常上網。

4 LED 指示燈狀態說明
指示燈 狀態 說明
WPS / Reset 常亮 (Solid) 設備正在執行恢復出廠預設值 (Reset)
閃爍 (Blinking) WPS 功能已啟動，正在搜尋與配對路由器
熄滅 (Off) WPS 未啟用 / 處於正常運作狀態
WLAN (無線) 閃爍 (Blinking) 無線網路正常運作中，正在發送/接收封包
熄滅 (Off) 未連線至無線網路或 WLAN 功能關閉
Ethernet (有線) 閃爍 (Blinking) 與有線設備（如電視/電腦）資料傳輸中
熄滅 (Off) 未檢測到有線網線連接
5 恢復出廠設定與疑難排解 (Troubleshooting)
🔄 恢復出廠設定 (Reset)
  • 一般重置：通電狀態下長按 Reset 鈕 3~5 秒，至 WPS 燈常亮後放開。
  • 強制重置：拔下電源 -> 按住 Reset 鈕不放 -> 插上電源 -> 等待 Port 燈亮起後放開。
⚠️ 常見問題解決
  • 無法登入 192.168.1.252：確認已關閉電腦 Wi-Fi，且網卡 IP 已設為 192.168.1.3。
  • 相容性須知：不支援企業級驗證 (Enterprise Wi-Fi) 及部分 Mesh Wi-Fi 系統。
💡 提示：使用網頁手動設定完成後，請務必將電腦以太網卡重新設定為「自動取得 IP 位址 (DHCP)」，否則電腦將無法正常存取網際網絡。
